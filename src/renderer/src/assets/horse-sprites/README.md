# 马匹像素素材

每匹马一个 PNG 精灵图，丢进这个目录即可。

完整作图规格见 `C:\D\Veridian\马匹素材规格.md`。

## 命名

小写英文加连字符，与外观对应：

```
horse-palomino.png
horse-chestnut.png
horse-gray-dapple.png
```

## 每个文件附一行说明

程序无法从 PNG 本身推断出帧尺寸和每行帧数（一张 192×64 的图，可能是 6 帧 32×32，也可能是 4 帧 48×32）。
所以每交一个文件，附一行：

```
horse-palomino.png  帧 32x32  第0行 idle 4帧  第1行 walk 6帧
```

## 不要放进这里

- `.aseprite` / `.psd` 源文件 —— 请自己保管，不要进仓库（会让打包体积翻几倍）
- GIF、序列帧散图 —— 用不上
- 带背景的图 —— 背景必须完全透明
